Network Guard Proxy

A lightweight reverse proxy and application-level firewall written in Go.

Features

  • Configurable security rules with IP CIDR, path, method, and header matching
  • Priority-based rule evaluation with first-match-wins semantics
  • REST API for rule and log management
  • Web UI dashboard for monitoring and configuration
  • SQLite persistence for rules and request logs
  • Graceful shutdown and clean architecture

Quick Start

go build ./cmd/networkguard/
cp config.example.yaml config.yaml
./networkguard --config config.yaml

Visit Getting Started for full setup instructions.
